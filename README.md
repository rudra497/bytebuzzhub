## What's inside

- `index.html` — the whole site (single file, no build step, no JavaScript dependencies)

- `assets/products/*.webp` — product photos (Wikimedia Commons, CC0/CC BY/CC BY-SA — see credits.html)
- `favicon.svg` — hexagon-and-bolt mark

## Sections

1. Hero — shop intro with WhatsApp + call buttons
